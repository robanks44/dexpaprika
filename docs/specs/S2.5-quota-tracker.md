# S2.5 spec — Provider quota tracker

## Purpose

REFERENCE_INDEX §3b: config-driven, per-upstream quota accounting every later
client (S3+) sits behind. Rate limits enforced from the queryable
`api_call_log` (shared DB ⇒ enforced per UPSTREAM, not per client instance);
weighted-credit providers (CoinStats 400/DeFi call, Krystal ~10/call) and
flat providers (DexPaprika 1=1) are both first-class. Adding a provider is
config, not code.

## Public interface — `dexpaprika.quota`

- Packaged seed `quota/providers.json`: per-provider `name`, `base_url`,
  `rate_limit`, `rate_period` (second|minute|hour|day), `has_credits`,
  `credit_limit` (nullable = no known monthly cap), `free_tier`,
  `endpoint_costs` ({fnmatch pattern → credits}). Seeded rows (from §3b +
  session-verified docs): dexpaprika 30/min, 200k credits/mo flat;
  gmx 120/min (no documented ceiling — conservative, VERIFIED_FINDINGS §2);
  krystal 60/min, 50k units, default weight 10; coinstats 10/min, weighted —
  `wallet/defi*`=400, `coins*`=2, no known cap (plan-dependent);
  etherscan 5/sec; zerion 10/sec, 2000/mo (`sync=true` is a correctness rule,
  §0.1b, not quota); hyperliquid 1200 weight/min, `clearinghouseState`=2;
  geckoterminal 30/min; coingecko 10/min.
- `QuotaTracker(conn, now=None)` — `now` injectable for tests.
  - `ensure_providers()` — idempotent upsert of the seed into `providers` +
    `provider_endpoint_costs` (config tables are the runtime truth; the JSON
    is just the shipped default).
  - `endpoint_credits(provider, endpoint) -> int` — longest matching fnmatch
    pattern wins; default 1 (unweighted providers are the plain case, not a
    special case).
  - `check(provider, endpoint) -> QuotaVerdict(allowed, wait_seconds, reason)`
    — sliding window over `api_call_log` for the rate limit; calendar-month
    (UTC) credit sum vs `credit_limit` for budgets. Deny BEFORE exceeding.
  - `record(provider, endpoint, *, status, latency_ms, correlation_id)` —
    append to `api_call_log` with resolved credits.
  - `wait_for_slot(provider, endpoint, sleeper)` — sleep-loop until allowed;
    raises `QuotaExceededError` when the block is a credit budget (sleeping
    doesn't refill a month).
  - `summary(provider)` / `summaries()` — spend vs budget (window count,
    month credits, pct_used) for the CLI and S8 alert rules (80% threshold
    is an S8 alert rule; the tracker only reports pct_used).
- CLI: `dexpaprika quota [--provider NAME] --json` — summaries from the log.

## Error cases

- Unknown provider → `QuotaError` (clients must register config first).
- Credit budget exhausted → check denies with reason `credit-budget`;
  `wait_for_slot` raises instead of sleeping into next month.
- DB missing/unmigrated → actionable error pointing at `db migrate`.

## Standards obligations

- Enforce per upstream, not per client instance (§3b) — state lives in the
  shared DB, verified by a two-instance test.
- Zero-network tests; injectable clock and sleeper (frozen-time discipline).
- Coverage ≥90% on the tracker (core logic).

## Probe gate (Step 2b)

N/A — the tracker reads no external source; it is local accounting over S2
tables. Provider seed values come from session-verified reference docs
(coinstats/krystal/§3b) and are config, revisited per-client at S3+ probes.
