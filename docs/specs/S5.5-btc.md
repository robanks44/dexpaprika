## Reference gate

`reference\bitcoin--integration-guide.md` (verified live 2026-08-01):

- **Primary Blockstream Esplora** (`https://blockstream.info/api`,
  500k req/month free, enterprise SLA) with **mempool.space fallback**
  (same Esplora API shape) — the doc's recommended failover pair.
- Balance = `chain_stats.funded_txo_sum − chain_stats.spent_txo_sum`
  (satoshis); pending adds the `mempool_stats` delta. All amounts in
  sats — integers, scaled to BTC by 1e8.
- No Bitcoin library needed: balance tracking is one GET per address;
  parsing libs (bitcoin-utils etc.) matter only for tx building — out
  of scope.

## Public interface — `dexpaprika.clients.btc`

- `BtcAddressStats` (pydantic): `address`, `confirmed_sats: int`,
  `pending_sats: int`, `tx_count: int`, `unconfirmed_tx_count: int`,
  `balance_btc: Decimal` (exact sats/1e8), `source` (which peer served).
- `BtcClient(conn, *, settings, clients)` — peer ring over
  `btc_esplora_peers` (config, default blockstream then mempool), one
  quota-gated HttpTransport per peer (providers `blockstream` 60/min +
  500k monthly credits, `mempool` 30/min conservative — doc table);
  first healthy peer wins, next peer on TransportError (GMX pattern).
- `get_address(address) -> BtcAddressStats`;
  `record(wallet, stats, ts)` — positions upsert (venue `native`,
  chain `bitcoin`, kind `holding`, group `holdings`, external_id `btc`)
  + observed event `{symbol: BTC, amount, confirmed_sats, pending_sats,
  source}` (amount = Decimal string).

## Integration

- `snapshot --kind holdings` (and `all`) now ALSO iterates included
  `btc`-family wallets: one Esplora read per wallet, recorded through
  the same lifecycle pipeline, then a snapshots row
  (`chain='bitcoin'`, `block_number NULL` — off-chain-pinned source
  carries its timestamp, per §2). EVM kinds (lp/hedge/defi) unchanged;
  a registry with only BTC wallets no longer errors for holdings.
- `report` renders the BTC row through the existing `holding` branch
  (symbol + amount).
- Healthcheck reachability deliberately unchanged: Esplora failures
  surface as nonzero snapshot exits + the staleness alert (documented).
