# S4.5 spec — EVM on-chain read layer

## Purpose

Block-pinned, batched, failover-hardened on-chain reads for Base + Arbitrum:
the layer S5 (LP discovery) and S7 (range logic) build on. Raw JSON-RPC +
vendored ABI helpers over the shared quota-gated transport.

## Probe evidence (Step 2b — 2026-08-02, `probes/out/s45/pinned_multicall.json`)

- Hand-built `aggregate((address,bytes)[])` calldata executed live on BOTH
  chains (encoding validated against real responses; committed as fixtures).
- Base: aggregate at pin 49423950 → blockNumber tripwire EXACT match;
  chainId 8453; pool tick −201118 (sign-extended) + liquidity in one batch.
- **PROBE CATCH (standards correction):** on Arbitrum, Multicall3
  `getBlockNumber()` returns the **L1 (Ethereum) block** (~25.66M), not the
  L2 block (~490M) — `block.number` is L1-approximated on Arbitrum. The
  ENGINEERING_STANDARDS §2 tripwire as literally written would ALWAYS fail
  there. Fix (probe-verified): per-chain tripwire call inside the same
  batch — Base uses `Multicall3.getBlockNumber()`; Arbitrum uses
  `ArbSys(0x…0064).arbBlockNumber()` (selector `0xa3b1b31d`), which matched
  the pin exactly at 490181680. Deviation flagged to Richard.
- arb1 UA requirement re-confirmed (all requests send `User-Agent: dexpaprika/1.0`).

## Design decision (ADR)

Raw JSON-RPC + vendored ABI helpers instead of the web3py dependency: the
mapped reference doc's patterns ARE raw `eth_call` + manual decoding; web3py
would add a ~30-package surface for no additional capability here
(ENGINEERING_STANDARDS §3 dependency hygiene). The doc's PATTERNS (selectors,
sign-extension, block pinning, Multicall3, ring failover, UA header) are all
adopted; the dependency is not. Selectors are computed with the vendored
keccak (probe-pinned: `arbBlockNumber()` → `0xa3b1b31d`).

## Public interface

### `dexpaprika.chains.abi`

- `selector(signature) -> str` (keccak-based, `0x`+8 hex)
- `encode_call_aggregate(calls: list[tuple[address, data_hex]]) -> str` —
  Multicall3 `aggregate` calldata (probe-fixture-pinned byte-for-byte)
- `decode_aggregate(hex) -> tuple[int, list[bytes]]`
- `decode_uint(word_bytes)`, `decode_address(word_bytes)`,
  `sign_extend(value, bits)` (int24 ticks), `encode_uint(value)` arg padding
- Constants: `MULTICALL3` (same both chains), `ARBSYS`, chain ids.

### `dexpaprika.chains.rpc`

- `HttpTransport.post_json(...)` added to the shared transport (same quota/
  retry/breaker/Decimal discipline as GET).
- `EvmRpcClient(conn, chain, *, settings, clients=None, sleeper, clock)` —
  ring of transports over `settings.{chain}_rpc_urls`, provider
  `"<chain>-rpc"` (new S2.5 seed entries), every request with the UA header.
  - `rpc(method, params)` — ring failover on transport errors; JSON-RPC
    error objects: reverts fail fast, transient errors rotate the ring.
  - `block_number()`, `resolve_pin(margin=3)`
  - `call(to, data, block)` — single `eth_call`
  - `aggregate(calls, block) -> (int, list[bytes])`
  - `snapshot(kind, extra_calls=()) -> PinnedSnapshot` — resolve pin; one
    batch = [per-chain block tripwire, chainId] + extra, executed at the
    pin; assert tripwire == pin (`PinMismatchError` — lagging node) and
    chainId matches config; record a `snapshots` row (ts, chain,
    block_number, kind); return block + decoded-order results.

### Config / seed changes

- `arbitrum_rpc_urls` default extended to the reference matrix order
  (arb1 → publicnode → llamarpc); Base gains `mainnet.base.org` LAST.
- New quota providers: `base-rpc`, `arbitrum-rpc` (120/min conservative).

### CLI

```
dexpaprika chain snapshot [--chain base|arbitrum|all] --json
```

Pins, verifies tripwire + chainId, records `snapshots` rows, reports pins.

## Error cases

- Tripwire mismatch → `PinMismatchError` naming pinned vs returned block
  (lagging load-balanced node); snapshot NOT recorded.
- chainId mismatch → error (misconfigured ring).
- Whole ring dead → error naming every endpoint's failure.
- Revert (`execution reverted`) → immediate clear error, no ring rotation.
- Archive-depth reads are out of scope (public RPCs prune; documented).

## Standards obligations

- Block-pinned snapshots per §2 with the CORRECTED per-chain tripwire.
- Quota-gated per upstream ring; UA header on every call.
- Coverage ≥90% on abi + rpc modules; encoding pinned to live fixtures.
