# S9.5 spec — Network-configurable executor (Arbitrum Sepolia testnet)

## Purpose

Let the S9 executor target a chosen GMX chain so the live order path can be
rehearsed on **Arbitrum Sepolia testnet** before mainnet. Richard's decision
(2026-08-02): testnet rehearsal first, off his Windows machine, then promote
to cloud/mainnet. Setup method: GMX website One-Click Trading.

Corrected fact (verified 2026-08): GMX perpetuals run on Arbitrum
(42161 / Sepolia 421614) and Avalanche (43114) only. **Base is NOT a GMX
venue** — Base Sepolia cannot host this rehearsal. The config rejects any
non-GMX chain id.

## Reference gate

- Official GMX SDK v2 docs — `GmxApiSdk({chainId})` supports Arbitrum
  Sepolia (421614) for testing; the same `prepareEditOrder`/`submitOrder`
  path used on mainnet.
- No new upstream; the change is pure parametrization of the S9 sidecar.

## Change

- `config.py`: `gmx_chain_id` (default 42161) + `execution_account`
  (default Richard's wallet); `gmx_chain_id` validated against the GMX
  venue set {42161, 421614, 43114}.
- `cli.py` `_sidecar_runner`: passes `GMX_CHAIN_ID` + `GMX_ACCOUNT` into
  the sidecar env for every mode (key still submit-only).
- `executor/gmx_exec.cjs`: reads chain + account from env (mainnet
  fallback keeps the standalone probe working).

Everything else — the gate chain, approval, audit, idempotency — is
identical; testnet just points the same machinery at Sepolia.

## Probe evidence (Step 2b)

`probes/out/s9/testnet_read.json` — live read-only fetch on chainId
421614 returned ok (0 orders, expected: no testnet position yet),
proving the SDK reaches the Arbitrum Sepolia deployment.

## Test focus (offline)

- Config: mainnet defaults; testnet env overrides; a non-GMX chain
  (Base 8453) is rejected.
- Sidecar env: chain + account passed through; the subaccount key still
  reaches ONLY submit mode.
- Sidecar source: no hardcoded chain/account driving behaviour.

## Done criteria

Gate + audit green; verifier PASS incl. a live read-only smoke on
Arbitrum Sepolia. The full armed testnet nudge is Richard's supervised
